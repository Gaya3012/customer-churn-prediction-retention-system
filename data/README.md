# Dataset

Place the IBM Telco Customer Churn CSV in this folder with this exact filename:

`WA_Fn-UseC_-Telco-Customer-Churn.csv`

The CSV should contain the original IBM Telco Customer Churn columns, including
`customerID`, `TotalCharges`, and `Churn`. The training script accepts a custom
path with `--data` if you prefer a different filename or location.

The dataset is not bundled with this project. Obtain it from IBM's Telco
Customer Churn sample data / the IBM-hosted dataset on Kaggle, and make sure you
have permission to use and redistribute it as appropriate.
