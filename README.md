# Customer Churn Prediction & Retention System

An end-to-end machine-learning application that estimates telecom customer churn probability, assigns a Low/Medium/High risk band, and suggests a retention action. The project uses IBM's Telco Customer Churn dataset, a leakage-safe Scikit-learn preprocessing/model pipeline, a Flask web interface, and a JSON REST endpoint.

> **Dataset required:** The CSV is not included. Download the IBM Telco Customer Churn dataset and place it at `data/WA_Fn-UseC_-Telco-Customer-Churn.csv`. See [data/README.md](data/README.md).

## Architecture

1. `src/preprocess.py` loads and validates the CSV, separates the target, and builds a `ColumnTransformer`. Numeric fields use median imputation and standard scaling; categorical fields use most-frequent imputation and one-hot encoding.
2. `src/train.py` makes a stratified train/test split **before fitting any preprocessing**, trains the three candidate models, evaluates held-out data, writes EDA/evaluation outputs, and saves the best complete pipeline with Joblib.
3. `src/evaluate.py` calculates accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrices.
4. `app.py` loads the saved pipeline for browser and JSON predictions and validates incoming values.

Preprocessing is fit only against the training split and is bundled with the classifier. Unknown categories are safely ignored by the encoder; missing numeric/categorical values use the fitted training-set imputers. `customerID` is excluded from model features. If `TotalCharges` is omitted from a prediction, the app estimates it as `tenure × MonthlyCharges`.

## Algorithms and selection

- Logistic Regression (`class_weight="balanced"`)
- Decision Tree (`class_weight="balanced"`)
- Random Forest (`class_weight="balanced"`)

The winner is selected by test-set ROC-AUC, with F1-score and accuracy as tie-breakers. The test split is for evaluation and model selection; for production use, validate the selected model on separate data and consider cross-validation and calibration.

## Setup (Windows PowerShell)

Run these commands from the project root. Python 3.10 or newer is recommended.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, use `.\.venv\Scripts\python.exe` instead of `python` in the following commands.

## Train and evaluate

After placing the CSV at the path above:

```powershell
python -m src.train
```

Or supply a custom CSV path:

```powershell
python -m src.train --data "C:\path\to\WA_Fn-UseC_-Telco-Customer-Churn.csv"
```

Training saves `models/churn_pipeline.joblib` and reports under `reports/`: `evaluation.json`, `model_metrics.csv`, model comparison and confusion-matrix figures, ROC curves, churn distribution, and customer-feature EDA.

## Run the Flask app

Train the model first, then run:

```powershell
python app.py
```

Open **http://127.0.0.1:5000** and submit a customer profile. Select each required service/customer attribute and enter tenure, monthly charges, and senior-citizen status. Total charges are optional and estimated if omitted. The result page shows the prediction, probability, risk band, and recommended action. `/health` returns application/model-file status.

## JSON API

`POST /api/predict` accepts `application/json`. All fields below are required except `TotalCharges`. Values are case-sensitive and should match the dataset categories.

```powershell
$body = @{
  gender = "Female"
  SeniorCitizen = 0
  Partner = "Yes"
  Dependents = "No"
  tenure = 12
  PhoneService = "Yes"
  MultipleLines = "No"
  InternetService = "Fiber optic"
  OnlineSecurity = "No"
  OnlineBackup = "Yes"
  DeviceProtection = "No"
  TechSupport = "No"
  StreamingTV = "Yes"
  StreamingMovies = "Yes"
  Contract = "Month-to-month"
  PaperlessBilling = "Yes"
  PaymentMethod = "Electronic check"
  MonthlyCharges = 85.5
} | ConvertTo-Json
Invoke-RestMethod -Uri http://127.0.0.1:5000/api/predict -Method Post -ContentType "application/json" -Body $body
```

A successful response has this shape:

```json
{
  "churn_prediction": "Yes",
  "churn_probability": 0.73,
  "risk_level": "High",
  "retention_recommendation": "Prioritize a personal retention outreach; review pricing, contract options, and support needs."
}
```

Validation errors return HTTP 400 with field-level details. A missing trained model returns HTTP 503 with instructions to run training.

## Notes

- The risk bands are probability thresholds for this project demo: Low `< 0.30`, Medium `< 0.60`, High `≥ 0.60`.
- This is a portfolio/decision-support example; model performance and retention actions should be reviewed before business use.
- Do not commit customer data or trained artifacts. They are excluded by `.gitignore`.
